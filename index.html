Back up your trips

One backup file holds all your trips. They're stored only on this phone. Save a backup file now and then, and keep it somewhere safe, such as your email or Google Drive. If you change phones or clear the app, restore from that file.

Restore from a backup

Trips in the backup file replace the same trips in the app, and any others are added. Trips that aren't in the file are left alone.
